# Source evidence is not a support verdict

An ADR source link should carry an exact code-owned source snapshot and its revision, not require a language model to retype an existing sentence. Hashing the complete item binds its decision, reason, scope and resolution history. It does not authenticate authorship or prove semantic support. Keep those claims separate.
